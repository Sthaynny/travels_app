# Módulo: Auth

> **Status**: Planejado — Fase 1 do roadmap

Autenticação de usuários via Firebase Auth.

## Escopo

- Login e cadastro com e-mail/senha
- Recuperação de senha
- Sessão persistente e route guard no GoRouter

## Dependências

- `firebase_core` — inicialização
- `firebase_auth` — autenticação

Requer arquivos de configuração Firebase (`google-services.json`, `GoogleService-Info.plist`).
